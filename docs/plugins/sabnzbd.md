# SABnzbd
## Example
```
sabnzbd:
  key: 123456
  url: http://localhost:8080/api?
  category: movies
```

## All possible parameters
```
sabnzbd:
  key: ...
  url: ...
  category: ...
  script: ...
  pp: ...
  priority: ...
  username: ...
  password: ...
```

## Override category
By setting [entry](/guide/entry) category you can override / specify sabnzbd category per item. To set it you can use plugins like <plugin:set>, <plugin:manipulate>. pp stands for post processing, you can set a path to a script which sohould be called after sabnzbd downloaded the file. Further you can modify the Priority which is used for a file by sabnzbd with the priority parameter, the valid values can be found [here](http://wiki.sabnzbd.org/api#toc36).

See [this recipe](/cookbook/series/series-sabnzbd) for example how to set category from a series name.
