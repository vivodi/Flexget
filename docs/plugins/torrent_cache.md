# Torrent cache

:::{caution}
It is disabled from being a built-in. See https://github.com/Flexget/Flexget/issues/2307.
:::

Builtin [url-rewriter](/guide/url-rewriters) which adds torrent cache service (torcache, torrage, etc) links for entries which have either magnet link as URL or have torrent_info_hash field defined.

Does not require or take configuration.
