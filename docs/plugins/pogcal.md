# Pogdesign Calendar
Produces an entry for each show you have checked on your tv show calender at [pogdesign.co.uk](http://www.pogdesign.co.uk/cat/). Useful with <plugin:configure_series> plugin.

## Configuration
Username and password for the website are the only configuration options:
```yaml
pogcal:
  username: me@here.com
  password: xxxx
```
